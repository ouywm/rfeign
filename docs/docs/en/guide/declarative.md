# Declarative API

The declarative API lets you define HTTP clients as Rust traits. rfeign generates the implementation at compile time — no boilerplate, no runtime reflection.

## #[http_client] Attribute

Apply `#[http_client(...)]` to a trait to declare it as an HTTP client interface.

```rust
#[rfeign::http_client(base_url = "http://localhost:8080")]
trait UserApi {
    #[rfeign::get("/users/{id}")]
    async fn get_user(&self, #[path] id: i64) -> rfeign::Result<User>;
}
```

### Parameters

| Parameter  | Description                              | Example                          |
|-----------|------------------------------------------|----------------------------------|
| `base_url` | Static base URL for all requests         | `base_url = "http://localhost"`  |
| `path`     | Common path prefix for all methods       | `path = "/api/v1"`              |
| `service`  | Service name for service discovery       | `service = "user-service"`       |

You can combine `service` with `path`:

```rust
#[rfeign::http_client(service = "user-service", path = "/api")]
trait UserApi {
    #[rfeign::get("/users/{id}")]
    async fn get_user(&self, #[path] id: i64) -> rfeign::Result<User>;
}
```

## Trait-Level Headers

Use `#[headers("Key: Value")]` to attach static headers to every request:

```rust
#[rfeign::http_client(base_url = "http://localhost:8080")]
#[headers("X-App: rfeign", "Accept: application/json")]
trait UserApi {
    #[rfeign::get("/users/{id}")]
    async fn get_user(&self, #[path] id: i64) -> rfeign::Result<User>;
}
```

## HTTP Method Macros

Annotate each trait method with an HTTP method macro and a path template:

```rust
#[rfeign::http_client(base_url = "http://localhost:8080")]
trait ApiClient {
    #[rfeign::get("/resources")]
    async fn list(&self) -> rfeign::Result<Vec<Resource>>;

    #[rfeign::post("/resources")]
    async fn create(&self, #[body] data: NewResource) -> rfeign::Result<Resource>;

    #[rfeign::put("/resources/{id}")]
    async fn update(&self, #[path] id: i64, #[body] data: NewResource) -> rfeign::Result<Resource>;

    #[rfeign::delete("/resources/{id}")]
    async fn delete(&self, #[path] id: i64) -> rfeign::Result<()>;

    #[rfeign::patch("/resources/{id}")]
    async fn patch(&self, #[path] id: i64, #[body] data: PatchData) -> rfeign::Result<Resource>;

    #[rfeign::head("/resources/{id}")]
    async fn exists(&self, #[path] id: i64) -> rfeign::Result<()>;
}
```

Supported macros: `#[get]`, `#[post]`, `#[put]`, `#[delete]`, `#[patch]`, `#[head]`.

## Method-Level Headers

Add static headers to a single method with `#[rfeign::header("Name", "Value")]`:

```rust
#[rfeign::get("/users/{id}")]
#[rfeign::header("X-Trace-Id", "abc-123")]
async fn get_user(&self, #[path] id: i64) -> rfeign::Result<User>;
```

## Generated Struct

For a trait named `UserApi`, the macro generates a struct `UserApiClient`:

```rust
// Generated by the macro
#[derive(Clone)]
pub struct UserApiClient {
    client: rfeign::client::Client,
}

impl UserApiClient {
    pub fn new(client: rfeign::client::Client) -> Self;
    pub fn base_url() -> Option<&'static str>;
    pub fn service_name() -> Option<&'static str>;
    pub fn path() -> &'static str;
}
```

### Usage

```rust
use rfeign::{ClientBuilder, ReqwestTransport};

let client = ClientBuilder::new(ReqwestTransport::new())
    .base_url("http://localhost:8080")
    .build();

let api = UserApiClient::new(client);
let user = api.get_user(42).await?;
```

The generated struct implements the trait and is `Clone`, so it can be shared across tasks freely.
